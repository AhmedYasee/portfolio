# Ahmed Yaseen · Portfolio

Personal portfolio site: a dark, animated single page covering my work as a software engineer (backend/.NET, SCADA tooling, desktop apps) and selected projects.

## Stack

Plain HTML, CSS and JavaScript. No build step. Fonts from Google Fonts (Fraunces, Inter, JetBrains Mono).

- `index.html` — page content
- `styles.css` — dark theme, glassmorphism, hover effects
- `script.js` — hero particle constellation and typing effect (both respect `prefers-reduced-motion`)
- artwork embedded in `styles.css` as a data URI

## Hosting

Served with GitHub Pages from the `main` branch root.

## Sections

Hero, About, What I work with, Selected projects (SPCS, Food Delivery & Restaurant Management, Accounting System), Experience, Recognition & training, Contact.
